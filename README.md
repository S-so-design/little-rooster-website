# 🐓 Little Rooster Website

A beginner-friendly e-commerce website for a small liquor store called **Little Rooster**, built with **HTML, CSS**, and basic JavaScript. The site showcases product categories, offers, customer reviews, and basic account management. This project is a learning exercise to practice web development and build a portfolio.

---

## 🚀 Live Demo

Check out the live website on GitHub Pages:  
[https://s-so-design.github.io/little-rooster-website/](https://s-so-design.github.io/little-rooster-website/)

---

## 📂 Project Overview

- **Home Page**: Displays branding, search bar, product categories, offers, and customer reviews.  
- **Account Management**: Create account, sign in, and admin sign in pages.  
- **Product Collection**: Wines, Champagne, Beer, Vodka, Tequila, Whiskey, Seltzers, Non-alcoholic drinks.  
- **Offers Section**: Example discounts like Tito’s Vodka at 10% below state minimum.  
- **Delivery & Pickup**: Options for customers to pick up or have orders delivered.  
- **Footer**: Contact info, About Us, Store info, Customer Service, legal & privacy links.
